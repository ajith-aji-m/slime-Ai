Data Parsing Logic

Here is the Python script utilized to aggregate and clean the raw CSV data, extracting the key revenue streams:

python 
import pandas as pd
import numpy as np

# Load Q3 Raw Data
df = pd.read_csv('q3_metrics_raw.csv')

# Clean and aggregate by revenue stream
def process_revenue(dataframe):
    # Filter out cancelled orders
    valid_orders = dataframe[dataframe['status'] == 'completed']
    
    # Group and sum
    revenue_summary = valid_orders.groupby('stream_type')['amount'].sum().reset_index()
    revenue_summary = revenue_summary.sort_values(by='amount', ascending=False)
    
    return revenue_summary

results = process_revenue(df)
print(results)
